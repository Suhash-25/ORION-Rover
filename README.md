# Project ARES

**Adaptive Robotic Exploration System**

Project ARES is a research-oriented autonomous robotics platform focused on building a cognitive rover capable of rapid adaptation to unknown environments using Meta Reinforcement Learning.

## Rover

**ORION**

## Vision

To build an autonomous rover that can perceive, understand, reason, learn, and adapt while exploring previously unseen environments without human intervention.
